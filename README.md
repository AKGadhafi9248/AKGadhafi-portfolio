
# AKGadhafi Salesforce Portfolio

A personal portfolio website built on Salesforce Experience Cloud to showcase my profile, technical skills, projects, and Salesforce development knowledge.

## 🚀 Project Overview

This project demonstrates hands-on experience with Salesforce development using Lightning Web Components (LWC), Apex, SOQL, and Salesforce Experience Cloud.

The portfolio is designed to provide a dynamic and responsive user experience while following Salesforce development best practices.

## 🛠️ Technologies Used

- Salesforce Experience Cloud
- Lightning Web Components (LWC)
- Apex
- SOQL
- JavaScript
- HTML
- CSS
- Salesforce Flow
- Salesforce Data Model

## ✨ Key Features

- Personal profile and professional summary
- Technical skills showcase
- Project portfolio
- Reusable Lightning Web Components
- Dynamic data retrieval using Apex and SOQL
- Responsive user interface
- Experience Cloud site configuration
- Salesforce automation using Flow

## 📂 Salesforce Development

### Lightning Web Components
- Created reusable and modular LWC components
- Implemented component communication
- Used JavaScript for client-side functionality
- Designed responsive UI using HTML and CSS

### Apex
- Developed Apex classes and controllers
- Used SOQL for Salesforce data retrieval
- Implemented server-side business logic
- Followed Salesforce governor limits and best practices

### Experience Cloud
- Built and configured a Salesforce Experience Cloud site
- Created custom pages and components
- Integrated custom LWCs into Experience Cloud pages

## 🎯 Learning Objectives

This project was developed to strengthen my practical knowledge of Salesforce development and to gain hands-on experience with:

- Apex development
- Lightning Web Components
- SOQL
- Salesforce automation
- Experience Cloud
- Salesforce data modeling
- Component-based development

## 👨‍💻 About Me

I am a Salesforce Platform Developer I (PD1) certified professional with 2 years of IT experience and a background in SAP HANA database operations and support.

I am transitioning into Salesforce development and actively building hands-on projects using Apex, LWC, SOQL, Flow, and Experience Cloud.

## 📌 Project Status

Completed as a personal Salesforce development project and continuously enhanced with additional Salesforce features and best practices.
